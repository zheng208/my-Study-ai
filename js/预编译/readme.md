# 预编译
- 预编译是指在代码执行前一时刻，对代码进行一些处理，比如替换宏定义、展开函数等。
（v8引擎内部有一个编译部门和一个执行部门）

# 函数体内的预编译
1. 创建一个执行上下文对象 AO：{}
2. 找形参和变量声明，将形参和变量名作为AO的属性，值为undefined
3. 将形参和实参统一
4. 在函数体内找函数声明，将函数名作为AO的属性，值为函数体
5. 执行函数体内的代码
6. 返回AO

# 全局的预编译
1. 创建一个执行上下文对象 AO：{}
2. 找全局变量声明，将变量名作为AO的属性，值为undefined
3. 找全局函数声明，将函数名作为AO的属性，值为函数体
4. 找全局函数声明，将函数名作为AO的属性，值为函数体
5. 返回AO

# v8的调用栈
- 调用栈是指在代码执行过程中，记录函数调用的顺序和环境的栈结构。
