 # 构造函数
 - 被new调用的函数，用于批量创建对象
 1. js官网提供了多个构造函数
    - object
    - array
    - function
    - date
    - regexp
    - error
    ## prototype 原型
    - prototype 是每个函数天生就拥有的属性，且他是一个对象

    ## __proto__对象原型（隐式原型）
    - __proto__是对象天生拥有的属性，且他是个对象
    ### 实例对象的隐式原型等于构造函数的显示原型 new干的
    - new操作符会创建一个新对象，这个对象的隐式原型就等于构造函数的显示原型
    - v8引擎在访问对象中的属性时，会先去对象本身显示拥有中查找，如果没有，就会去对象的隐式原型中查找，直到找到为止。
# 包装类
- 原始类型不能添加属性和方法

1. 当用户创建一个字面量时，v8引擎会自动调用对应的构造函数new xxx（），创建一个对象对象，然后返回这个对象
2. 因为原始类型不能添加属性和方法，所以v8引擎会在创建对象后，立即做一个拆箱操作
3. 所以给原始类型添加属性和方法，最后访问得到的其实是实例对象上不存在的属性和方法，也就是undefined
