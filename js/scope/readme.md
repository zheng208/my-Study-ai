# 作用域
1. 全局作用域
2. 函数作用域
3. 块级作用域
- 作用域的访问规则：内层作用域可以访问外层作用域的变量，但是外层作用域不能访问内层作用域的变量
- 标识符定义在哪，谁是我的父级作用域
## 词法作用域
- 词法作用域是指在函数调用时，标识符的访问规则是根据函数的定义位置来确定的，而不是根据函数的调用位置来确定的

# 欺骗词法作用域
- 欺骗词法作用域是指在函数调用时，标识符的访问规则是根据函数的定义位置来确定的，而不是根据函数的调用位置来确定的
- 例如：
```js
let a=1;
if(1){
    console.log(a); //暂时性死区
    let a=2;
}
eval()
```
# 栈
- 栈是指在函数调用时，将函数的变量环境压入栈中，当函数执行完毕后，将栈顶的变量环境弹出栈
- 栈的大小是有限的，如果栈溢出，就会导致内存泄漏

# 调用栈
- 调用栈是指在函数调用时，将函数的变量环境压入栈中，当函数执行完毕后，将栈顶的变量环境弹出栈
- 调用栈的大小是有限的，如果调用栈溢出，就会导致内存泄漏!
