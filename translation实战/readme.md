# 前端的三驾马车
1. html 主要用来描述网页的结构和内容，是网页的基础语言
2. css 主要用来描述网页的样式和布局，是网页的样式语言
3. js 主要用来描述网页的交互和动态，是网页的脚本语言

# 这是一个翻译网站
1. 当用户点击翻译按钮时，我们要先获取用户输入的文本
2. 将用户输入的文本传输给LLM （远程的，本地的）
  - ollama：是一个集成环境，允许我们将LLM源码直接运行在ollma这个容器内
3. 获取到LLM 会返回翻译后的文本展示在页面上
